Flag logic (today = ).  Live = Completed / Phase 2 / Hyper Care / Moved to Support.  Due this month = ETA in Aug 2026, not yet live.  Missed = ETA before this month, still not live (excludes Churned).  Upcoming = ETA after this month.  Months before 2026 are hidden from the filter and month charts; the cumulative line is seeded with pre-2026 live projects so the total stays accurate. Goal fixed at 10/month.

Data source. The weekly Zoho Projects export, published to data/golive.json. Everyone reads that one file, so all viewers see the same numbers — no API key and no login to Zoho needed. Go-Live ETA is Zoho’s Current ETA column and Deal Value is Deal Amount, so wrong figures get fixed in Zoho and re-exported, not edited here. Internal accounts (Golden Account, MVP, RBP Internal Use) are dropped on upload, and rows whose ETA cell is - count as no ETA. The header shows how old the export is and warns when it is over a week old. To refresh it: Ctrl+A → drop in the new export → Publish.
